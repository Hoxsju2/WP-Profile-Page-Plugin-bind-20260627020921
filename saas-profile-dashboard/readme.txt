Modernize WordPress user profile pages with a SaaS concept, custom tabs, and WooCommerce integration.

== Description ==

SaaS Profile Dashboard transforms the standard WordPress user profile page into a modern, SaaS-style dashboard. Perfect for membership sites, online stores, and any WordPress site that wants to provide users with a professional profile experience.

= Key Features =

* **Modern SaaS Design**: Clean, professional interface that users will love
* **Custom Tab System**: Create unlimited tabs with shortcodes or external URLs
* **WooCommerce Integration**: Built-in support for orders, downloads, and wishlist
* **AJAX Loading**: Smooth, fast tab switching without page reloads
* **Admin Management**: Easy-to-use admin panel for managing tabs
* **Profile Replacement**: Replaces default WordPress profile for non-admin users
* **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices

= Perfect For =

* Membership sites
* Online stores
* Learning management systems
* Any site needing professional user profiles

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/saas-profile-dashboard` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress
3. Use the Profile Dashboard menu in admin to configure your tabs
4. Visit `/profile/` on your site to see the new profile page

== Frequently Asked Questions ==

= How do I add a new tab? =

Go to Profile Dashboard > Manage Tabs in your WordPress admin and click "Add New Tab". You can add content via shortcodes or external URLs.

= Does this work with WooCommerce? =

Yes! The plugin includes built-in WooCommerce integration with shortcodes for orders, downloads, and wishlist functionality.

= Can I customize the design? =

Yes, the plugin uses CSS classes that you can override in your theme. All styles are contained in the `spd-` prefix.

= Will this affect admin users? =

No, admin users will continue to see the standard WordPress profile page. Only non-admin users get the new SaaS dashboard.
